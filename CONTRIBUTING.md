# Contributing to Auto-UML

## Requirements

- A recent stable Rust toolchain. The crate is on edition 2024, so Rust 1.85 or newer.
- [prek](https://github.com/j178/prek) 0.4.10 or newer for the git hooks (see below).
  `prek.toml` declares that floor via `minimum_prek_version`.
- Optional: [hyperfine](https://github.com/sharkdp/hyperfine) if you want to run
  `docs/benchmark.sh`.

## Building and running

```fish
cargo build --release

# Point the tool at anything, including this repository
cargo run -- --lang rust --source-code src/
```

## Tests

Run the suite from the repository root. The integration tests resolve their fixture paths relative to the working directory, so they fail from anywhere else.

```fish
cargo test --no-fail-fast   # unit, integration, and doctests
cargo test rust             # every case for one language
cargo test rust::generics   # a single case
cargo test --doc            # just the usage examples in src/lib.rs
```

Integration tests are named `<language>::<category>` and are generated by the `lang_tests!` macro in `tests/integration_tests.rs`, driven by each `languages/<lang>/test.yaml`. The four categories are `simple_struct`, `impl_block`, `complex_types`, and `generics`. `test_stitcher_integration` separately covers multi-file type resolution against the fixture tree in `languages/stitch_test/`.

## Hooks and linting

Standards are enforced by prek hooks configured in `prek.toml`. Install them once:

```fish
prek install
```

That registers all three stages listed in `default_install_hook_types`: `pre-commit`,
`pre-push`, and `commit-msg`. Hooks with no explicit stage run at pre-commit.

### pre-commit

| Hook | What it does |
| ---- | ------------ |
| `trailing-whitespace` | Strips trailing whitespace. |
| `check-toml` | Validates every TOML file parses — `Cargo.toml`, `prek.toml`. |
| `check-yaml` | Validates every YAML file parses, which covers all `languages/*/config.yaml` and `test.yaml`. |
| `check-added-large-files` | Blocks oversized files from being committed. |
| `typos` | Spell check all files committed. |
| `prettier` | Formats the language example files. |
| `cargo-fmt` | `cargo fmt --all -- --check` |
| `cargo-clippy` | `cargo clippy --all-targets --all-features -- -D warnings`. Warnings are errors. |
| `cargo-check` | `cargo check --workspace --all-targets --all-features` |

### commit-msg

| Hook | What it does |
| ---- | ------------ |
| `typos` | A second `typos` instance, named "Spell check commit message", run against the message itself. |

### pre-push

| Hook | What it does |
| ---- | ------------ |
| `cargo-test` | `cargo test --workspace --all-targets --all-features` |

## Commits and pull requests

Commits follow Conventional Commits, with a scope where one applies:

```text
feat(kotlin): added support for kotlin
fix(cpp): addressed dropped params and missing generics
docs: updated the CLI reference to match the implementation
```
